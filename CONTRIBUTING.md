# Contributing

Thanks for your interest in Tzamun's open-source projects.

1. Open an issue first for anything larger than a small fix, so we can agree on the approach.
2. Fork the repository, create a branch, and keep each pull request focused on one change.
3. Make sure the project builds and its tests pass before you open the pull request.
4. Describe what changed and why in the pull request.

Security issues: please follow [SECURITY.md](SECURITY.md) instead of opening an issue.

Questions about our products or services: [tzamun.sa](https://tzamun.sa) · info@tzamun.sa
